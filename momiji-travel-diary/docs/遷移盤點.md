# 遷移盤點（Claude Artifact → GitHub Pages）

盤點日期：2026-10-29。來源：Claude Artifact 最新正式版本（V2.2.1）。

## 架構
- 純 HTML／CSS／JavaScript 單一檔案（約 85 KB），沒有 React、Vite 或任何 npm 套件，**不需要 Build**。
- 沒有前端路由（單頁，用 JS 切換分頁），重新整理與深層連結不會出現 404。

## 相依性
| 項目 | 在 Claude Artifact 的做法 | 移植後 |
|---|---|---|
| 六張正式插畫（WebP）與六張原始 PNG | 存在 Artifact 素材庫，網址 `/_blob/<id>`（共 13 處引用） | 改成相對路徑 `assets/img/…`；顯示圖的 SHA-256 與當初上傳的素材逐一相符；原始 PNG 與素材包 manifest 的 SHA-256 相符 |
| JSON 匯出 | 優先呼叫 Claude 的 `downloads` 能力 | 程式已有保護：偵測不到 `window.claude` 時，改用瀏覽器下載，並顯示可複製的文字框 |
| 字體 | Google Fonts `<link>` | 不變（需連網） |
| 儲存 | localStorage：`momiji-2026-v1`（行程、心得、行李、伴手禮、記帳）、`momiji-guide-v1`（小叮嚀） | 不變；新網址是新的瀏覽器儲存空間，需用 JSON 匯入匯出搬資料 |
| 後端、API、金鑰 | 無（沒有 fetch、沒有 Anthropic API、沒有第三方服務） | — |
| 外部連結 | 官方網站連結（點擊才開啟） | 不變 |

## 受影響功能
- 無功能被移除或替換。唯一差異：Claude 專屬的下載功能在公開網站不存在，改走瀏覽器下載與文字備援。

## 已執行測試（本機，無網路環境，用 HTTP 伺服器模擬 `/momiji-travel-diary/` 子路徑）
- 五張首頁／每日圖、地圖底圖載入，比例正確，本站請求無 404。
- 功能回歸：首頁、行程勾選、印章、地圖、交通、工具箱、小叮嚀、JSON 匯入匯出（新舊格式、錯誤格式）全數通過。
